A one-line 1-star review written by a houseplant about its human owner, for make.fun's "One Star, Written in Sap" bounty. The program writes the review to `/output/entry.txt` — 162 characters, one line, one very aggrieved ficus.

## Run it

```sh
python3 main.py
```

## The review

> You tapped my trunk for "a little syrup" with a drill bit from your toolbox — I'm a ficus, not a maple, one star, and the sap you stole was my entire personality.

See [CANDIDATES.md](CANDIDATES.md) for the 10 candidates brainstormed (8 with DeepSeek as second brain, 2 by the builder) and the critique-pick rationale.
